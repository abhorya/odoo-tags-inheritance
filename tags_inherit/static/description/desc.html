Odoo Custom Tags Management Module

Module Version: 1.0

Compatible with: Odoo 17/18

This module enhances Odoo's filtering and categorization system by allowing users to assign Customer Tags, Vendor Tags, and Product Tags to different entities. It provides improved data organization and faster access to important records.

📌 Features

✅ Manage and assign Customer, Vendor, and Product Tags.

✅ Enhanced search filters based on tags.

✅ Group by tags in contacts, users, and product views.

✅ Intuitive tag dashboard for easier tag management.

✅ Seamless integration with Odoo CRM, Sales, and Inventory.

🔍 Screenshots

1️⃣ User Management with Tags

Users can be filtered based on Customer, Vendor, or Product Tags.

2️⃣ Contact List with Tag Filters

Quickly categorize and find contacts using custom filters.

3️⃣ Contact Details with Assigned Tags

Each contact can have specific tags assigned for easy classification.

4️⃣ Product Tagging

Tag products with relevant categories to enhance filtering in Sales and Inventory.

5️⃣ Tag Configuration

Admins can manage available tags through the Configuration Menu.

6️⃣ Tag Dashboard

A dedicated Tag Dashboard provides an overview of all tag categories.

⚙️ Installation

1. Download the module and place it in your Odoo addons directory.

2. Restart Odoo and go to Apps.

3. Search for "Custom Tags Management" and install the module.

4. Go to Contacts, Users, or Sales and start tagging your records!

🎯 Use Cases

  • Organizing customer/vendor lists based on industry, location, or services.
  • Filtering products efficiently in sales and purchase workflows.
  • Managing internal users by departments or roles.
