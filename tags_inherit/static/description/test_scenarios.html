# Tag-Based Access Control System - Test Scenarios ### Developed by Sabry Youssef

Basic Test Scenario

Setup Phase

1. Create Tags

  • Customer Tags: "Premium Customers", "Standard Customers"
  • Vendor Tags: "Preferred Vendors", "International Vendors"
  • Product Tags: "Electronics", "Office Supplies"
  • Account Tags: "Revenue Accounts", "Expense Accounts"

2. Configure Users

  • Sales Rep: allowed_customer_tags = "Premium Customers", allowed_product_tags = "Electronics"
  • Purchasing Agent: allowed_vendor_tags = "Preferred Vendors", allowed_product_tags = "Office Supplies"
  • Accountant: allowed_account_tags = "Revenue Accounts", allowed_customer_tags = "Standard Customers"
  • Manager: Access to all tags

3. Create Records with Tags

  • Customers: "ABC Corp" (Premium), "XYZ Inc" (Standard)
  • Vendors: "Supplier A" (Preferred), "Supplier B" (International)
  • Products: "Laptop" (Electronics), "Paper" (Office Supplies)
  • Account Tags: "Sales Revenue" (Revenue), "Office Expenses" (Expense)

Testing Phase

1. Test Tag Counts and Views

Test Expected Result Status
Check "Premium Customers" tag count customer_count = 1 □
Click customer count button Shows only "ABC Corp" □
Check "Preferred Vendors" tag count vendor_count = 1 □
Check "Electronics" tag count product_count = 1 □
Check "Revenue Accounts" tag count account_count = 1 □

2. Test User Access Control

User Should See Should Not See Status
Sales Rep "ABC Corp", "Laptop" "XYZ Inc", "Paper", all vendors, all account tags □
Purchasing Agent "Supplier A", "Paper" "Supplier B", "Laptop", all customers, all account tags □
Accountant "XYZ Inc", "Sales Revenue" "ABC Corp", "Office Expenses", all vendors, all products □
Manager All records None □

3. Test Search Functions

Test Expected Result Status
Search customers with has_my_customer_tag = True (as Sales Rep) Only "ABC Corp" appears □
Search vendors with has_my_vendor_tag = True (as Purchasing Agent) Only "Supplier A" appears □
Search products with has_my_product_tag = True (as Sales Rep) Only "Laptop" appears □
Search account tags with is_allowed_tag = True (as Accountant) Only "Sales Revenue" appears □

Multi-Company Test Scenario

Setup Phase

1. Create Companies

  • Company A (main)
  • Company B

2. Configure Company-Specific Tags

Tag Name Tag Type Company
Company A Premium customer Company A
Company B Premium customer Company B
Company A Vendors vendor Company A
Company B Vendors vendor Company B
Company A Products product Company A
Company B Products product Company B
Company A Accounts account Company A
Company B Accounts account Company B

3. Configure Multi-Company Users

User Companies Allowed Tags
Company A User Company A only Company A Premium, Company A Vendors, Company A Products, Company A Accounts
Multi-Company User Company A and B All Company A and B tags

4. Create Company-Specific Records

Record Company Tag
Customer A Company A Company A Premium
Customer B Company B Company B Premium
Vendor A Company A Company A Vendors
Vendor B Company B Company B Vendors
Product A Company A Company A Products
Product B Company B Company B Products

Testing Phase

1. Test Company-Specific Tag Visibility

Test Expected Result Status
Login as Company A User and check visible tags Can only see Company A tags □
Login as Multi-Company User and check visible tags Can see both Company A and B tags □

2. Test Company-Specific Record Visibility

Test Expected Result Status
Login as Company A User and check visible records Can see Customer A, Vendor A, Product A; Cannot see Company B records □
Login as Multi-Company User in Company A context Can see Company A records; Cannot see Company B records □
Switch Multi-Company User to Company B context Can see Company B records; Cannot see Company A records □

3. Test Cross-Company Operations

Test Expected Result Status
Try to assign Company B tag to Company A record Should fail or show warning □
Try to create record with wrong company tag Should fail or show warning □

Edge Case Tests

Test Case Expected Result Status
Create record with no tag All users should be able to see it □
Change tag on existing record Visibility should update accordingly □
Change user's allowed tags Record visibility should update immediately □
Create many tags (100+) System should handle large number of tags □

Module Information

Tag-Based Access Control System

Developed by: Sabry Youssef

This module provides a comprehensive tag-based access control system for Odoo, allowing fine-grained permissions based on tags assigned to records and users.

The system supports multi-company environments and provides security at the record level.
